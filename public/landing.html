Install OpenMind

Use hosted remote MCP for browser providers and desktop clients, or local npm stdio for clients that run tools on your machine.

Hosted one-command install

Configures supported clients and prints exact setup notes for browser providers.

npx @vindepemarte/openmind connect https://theopenmind.pro --all-clients

Local stdio install

Runs OpenMind through npm for local MCP clients and self-hosted Postgres.

npx @vindepemarte/openmind init --local --all-clients
